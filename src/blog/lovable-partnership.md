When someone asks Lovable to build an app, TanStack Start is now part of what makes that app work! Lovable is also joining us as a partner, putting support back into the open-source tools its platform depends on.

Their move to Start began with new projects on May 13, 2026. Lovable wanted to stay with React, render pages on the server, and build on an open framework that could run across hosting platforms. Those are choices we've put a lot of work into making possible.

There are practical benefits for the person building the app. A page can arrive with its content already rendered, and server functions let backend logic live alongside the application instead of requiring a separately deployed function for each piece.

We've also been working with Lovable on the TanStack guidance its AI uses when generating code. Starting from the skills we maintain, their team has been refining those rules around real projects. That's a useful place for collaboration, helping the generated code follow the framework's actual patterns.

Read [Lovable's explanation of the move](https://lovable.dev/blog/building-apps-using-tanstack-start) for the details. I'm excited to see what people build on this foundation, and grateful to Lovable for helping sustain it.
