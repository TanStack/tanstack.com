![TanStack + Cloudflare](/blog-assets/cloudflare-partnership/header.png)

TanStack should be useful wherever you choose to deploy. Cloudflare is backing that direction as a partner, supporting our open-source work and giving TanStack Start developers a path to running their apps on Workers.

There's engineering behind that path. Start's server rendering and server functions need to work in the deployment environment you choose, and our teams have been working through that integration as Start moves toward its 1.0 release.

## Support that keeps deployment open

Cloudflare's [September 23, 2025 announcement](https://blog.cloudflare.com/cloudflare-astro-tanstack/) puts the broader commitment into words. Cloudflare and Netlify are both supporting TanStack, even though they compete to host applications built with it. That helps us keep developing tools that developers can use across platforms.

I'm grateful for that support! It gives us more room to improve TanStack while keeping the project open and independent.

If Workers is where you want to run your app, our [Cloudflare partner page](/partners/cloudflare) links to the current deployment guides.
