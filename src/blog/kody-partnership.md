[Kody](https://kody.codes/?utm_source=tanstack&utm_medium=partner-blog&utm_campaign=tanstack-partnership-2026-11&utm_content=intro-link) is joining TanStack as a Bronze partner. Their support helps pay for the maintenance behind the libraries we ship.

If you've ever walked a coding agent through a release checklist and then had to teach the next session the same steps, you'll recognize the problem Kody works on. With Kody, you can save a workflow as a package, connect the credentials it needs, and call it again from another agent.

We care about this one because a lot of TanStack work is the same work, repeated: upgrading Router across a few apps, cutting a release, checking what changed in the latest Query. Agents are good at those jobs, but they forget how you like them done once the session ends. Kody's own app runs on TanStack Start, Router, and Query, so they know the routine too.

With Kody, you teach it once:

- Save your Router or Start upgrade steps as a package, so Claude Code, Cursor, Codex, or any agent you connect runs them the same way in every repo.
- Keep your release steps (changesets, publish, tag, notes) in one package, with your npm and GitHub credentials connected. The package uses them, and the agent never sees the raw tokens.
- Share those packages with your org, so your teammates' agents do it your way too.

Thanks to Kody for backing our maintainers. You can [read about the partnership](/partners/kody) or [connect your first agent](https://kody.codes/docs/connect-your-agent?utm_source=tanstack&utm_medium=partner-blog&utm_campaign=tanstack-partnership-2026-11&utm_content=connect-first-agent).
