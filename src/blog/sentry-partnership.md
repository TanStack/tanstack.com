An app can work perfectly on your machine and still fail for someone using it. When that happens, you need more to go on than a report that a page didn't load.

We're welcoming Sentry as a TanStack partner! Their error monitoring and performance tools help developers investigate what happened in production, connecting failures and slow requests to the code involved. That's useful context in an app where routing, data loading, and rendering all contribute to what a user sees.

Sentry's support helps us keep improving the open-source tools underneath those applications. It's a good fit for the work that continues after the first deployment, finding the problems real users encounter and getting them fixed.

For a Start app today, the [Sentry integration guide](https://docs.sentry.io/platforms/javascript/guides/tanstackstart-react/) is the place to begin. Thanks to the Sentry team for backing TanStack.
