A sign-in screen is only the beginning of authentication. The session has to survive navigation, protected pages need to know who's signed in, and the server has to check access before returning private data.

That's why we're excited to have Clerk supporting TanStack as a partner! Clerk focuses on the account and session experience, alongside the routing and application tools we're building with TanStack.

The collaboration has a concrete integration to show for it. Clerk released its [TanStack Start SDK beta on September 11, 2024](https://clerk.com/changelog/2024-09-11-tanstack-start-beta), giving Start developers a dedicated way to add authentication and authorization.

If you're adding Clerk to an app today, use the [current Start quickstart](https://clerk.com/docs/tanstack-react-start/getting-started/quickstart). Our [Clerk example app](/start/latest/docs/framework/react/examples/start-clerk-basic) also gives you a project to explore.

Thanks to the Clerk team for supporting the project and making this part of building an app easier.
