Your app is ready for a customer, and then their IT team asks whether it works with the company's identity provider. That can turn a sign-in feature into a much larger project.

WorkOS is joining TanStack as a partner to support developers building those kinds of applications. Its tools cover requirements like single sign-on, directory sync, and audit logs, the things a business may need before its employees can use your product.

For a TanStack Start app today, the [WorkOS AuthKit SDK](https://workos.com/docs/sdks/authkit-tanstack-start) provides the authentication and session integration. You can read the current user in a route loader or server function, and use that session when deciding what the application should return. Our [Start example](/start/latest/docs/framework/react/examples/start-workos) shows the integration in a working project.

We're grateful to WorkOS for backing TanStack and helping developers handle the identity requirements that come with growing a business application!
